# Fly Aural Lab · 果蝇音乐空间

音乐和歌声驱动的果蝇神经可视化：左侧是 MaleCNS 真实骨架的 40 个神经元子集，右侧是放大的彩色神经空间和自动活动的 3D 果蝇。

**真实结构，模拟活动。** 这不是实测脑成像、果蝇音乐喜好预测或物理闭环仿真。发光节点是骨架上的显示标记，不代表实测突触放电。详细假设和数据来源见 [MODEL-NOTES.md](MODEL-NOTES.md)。

## 使用

不需要 API 密钥、登录服务或构建步骤。使用 HTTPS 静态托管部署整个 `dist/` 目录，或本地启动：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 `http://127.0.0.1:4173/`。不要直接双击 HTML 文件。

- 音乐文件：拖入或选择本地音频。
- 麦克风：点击并授权，可对着唱歌；停止时释放麦克风。
- 网页音乐：粘贴链接。支持的视频可在页内播放；点击“网页声音”，选择播放所在标签页并勾选共享音频。
- YouTube 的播放事件不等于收到音频。禁止嵌入的视频只能尝试原网页；浏览器或平台限制可能导致无法播放或共享声音。
- 两个窗口都可拖动旋转、滚轮缩放、双击复位。动作无需选择。静音时活动衰减，飞行中的果蝇完成落脚后停驻。

## 隐私与部署

本项目不录制或上传声音，不保存访问者的文件名、网址或麦克风数据，不使用分析统计脚本。嵌入播放器直接连接其第三方网站，可能处理 IP 地址和播放器使用数据。不要将私人音频、截图、密钥或账号配置加入仓库。

如部署到 GitHub Pages，在仓库的 Pages 设置中选择 GitHub Actions，并采用上传 `dist/` 的静态站点流程。相对资源路径支持仓库子目录。分享 Pages 网页地址即可；公开 GitHub 仓库本身会显示仓库所属账号。

## 验证

```sh
node --test tests/*.test.mjs
```

第三方资产许可保留在 `dist/assets/` 和 `dist/vendor/`。MaleCNS 结构数据来源及查询记录保留在数据文件内；第三方资料的许可不因本仓库公开而改变。
